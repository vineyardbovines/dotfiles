## dotfiles

Dotfiles for my macos setup.

![](./term.png)

- Terminal: [cmux](https://cmux.com/) using zsh with [starship](https://starship.rs/) and [color-ls](https://github.com/athityakumar/colorls)
- Editor: [neovim](https://neovim.io/) with [vim-plug](https://github.com/junegunn/vim-plug)
- Tools: [mise](https://mise.jdx.dev/), [zoxide](https://github.com/ajeetdsouza/zoxide), [stow](https://www.gnu.org/software/stow/)

## Installation

```bash
./install.sh
```
